# Vidas

Installers and updates for Vidas. Vidas checks this page by itself and installs new versions, so these downloads are only needed for a first install.

## Vidas 2.1.0

- Mac: [Vidas-2.1.0.dmg](https://raw.githubusercontent.com/drixosio/vidas-releases/main/2.1.0/Vidas-2.1.0.dmg)
- Windows: [Vidas-2.1.0-setup.exe](https://raw.githubusercontent.com/drixosio/vidas-releases/main/2.1.0/Vidas-2.1.0-setup.exe)

- The same file in several formats, like logo.svg, logo.png, and logo.pdf, now shares one tile with a chip for each format. Click a chip to copy, drag, or preview that format. Formats never count as versions, so stacks stay accurate.
- Compare two versions side by side, with one zoom for both. When they’re the same shape, a slider and a difference view show exactly what changed. Right-click a stack and choose Compare Versions, select any two assets, or press C in a preview.
- Drag a tile over another tile and pause until it says Stack with, then let go to stack them. Passing over tiles on the way to another app does nothing, and it can be undone.
- Categories now go Logos, Colors, Fonts, Images, Icons, Videos, and Design Files, with the brand’s identity first and working files last, the order brand guidelines use.
- Logos, icons, and other artwork with a transparent background now sit on a fine dot grid instead of a checkerboard, so the artwork stands out more.
- Vidas now finds and installs its own updates on Mac and Windows, with nothing to set up. Settings, Updates still accepts another address if you need one.
